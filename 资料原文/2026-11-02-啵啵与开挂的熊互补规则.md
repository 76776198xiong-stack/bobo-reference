# 啵啵与开挂的熊：互补规则（草案）

日期：2026-11-02（北京时间）｜写：Claude｜状态：**作者已确认（2026-11-02）**
依据：作者本轮原话；7-11 已确认的《账号与内容路由基线》《内容生产与平台合集基线》（`原件快照/2026-10-26/06-工作区/0626-讨论-自媒体商业系统/03、05`）；10-31 高敏感文案思路（`会话日志/2026-10-31-claude-课程目录与复更卡点.md`）。

## 一、作者原话

> 你提的这个出口，又帮我回忆起来了一个事情，就是之前我思考过这个问题，就是啵啵和开挂的熊这个账号，他们两个内容是互补的。我不想在开挂的熊里面讲太多知识，比如说关于一件事情具体怎么做，其实就像教学类视频一样。但是啵啵可以承担这个作用。他把一个知识点掰开了，揉碎了，讲清楚，讲的有趣。所以说他们俩可以是互相导流的。……我们也可以拿一个具体的，比如说就是高敏感，我最近要写的这篇文章，放在开挂的熊里面的这个口播文案，举例看看哪部分让啵啵讲，哪部分让开挂的熊来讲。……我希望你可以帮我把这个判断给它量化一下，规则化一下。……为什么他们俩可以互补，或者说如何互补？怎么标准的互补？

（原话中的语音识别错误已更正：开国的熊→开挂的熊，倒流→导流，波波→啵啵。）

## 二、已有的规则（7-11 已确认）

- **主题不是路由器**：决定去向的是内容状态和用户关系，不是话题。
- 啵啵承接“可以去除个人背景并标准化、角色化”的内容。
- 开挂的熊的内容只有两层要求：把事情讲清楚；让用户看见创始人怎样分析、怎样判断。
- 一次路由的第 3 问：去掉创始人背景后是否仍然成立？

这些规则路由的是**整条内容**。本草案把同一个判断，用到**一条内容里面的每一段**上。

## 三、定义

| | 啵啵 | 开挂的熊 |
|---|---|---|
| 给什么 | **知识** | **判断** |
| 回答 | 是什么；为什么会这样；一般怎么做 | 这对你意味着什么；你处在哪个阶段；你该怎么选 |
| 内容来源 | 公共知识：研究、经典、教科书里查得到，有出处 | 熊的观点，以及熊的原创模型 |
| 成立条件 | 换任何人讲都成立 | 只有熊这么看；价值在于熊的分析过程 |
| 讲法 | 掰开揉碎，讲得有趣，能演出来 | 一个点讲透，展示怎么想 |

**为什么能互补**：观众要先懂“是什么”，才听得懂“你该怎么办”。知识讲长了，判断就被冲淡；判断没有知识垫底，又站不住。分给两个账号，熊的稿子只留判断，啵啵把知识讲足、讲有趣。两边各自更好，又互相需要。

## 四、规则

### 拆分：一段一段判断，三问决定去向

对一条内容里的每一段，按顺序问：

1. **这段是在对观众的处境下判断吗？**（“你现在……”“你该……”）
   - 是 → **熊**。
2. **这段是换任何人讲都成立的公共知识吗？**
   - 不是（熊的观点或原创模型）→ **熊**。
   - 是 → 问第 3 问。
3. **一句话（约 10 秒）讲得清吗？**
   - 讲得清 → 留在熊的稿子里，**一句话带过**。
   - 讲不清 → **拆给啵啵**。

### 边界：各自停在交接线上

4. **熊的稿子里，公共知识最多一句话。** 超过一句才讲得清的，一律拆出去。
5. **啵啵停在“是什么、为什么、一般怎么做”**，不替观众下“你该怎么办”的判断。结尾把判断交回熊，对上“熊派活”的身世。
6. **熊的原创模型归熊**，啵啵不讲，避免把开挂的熊的核心理论送给角色。

### 互导：只在两边都有料时配对

7. **熊 → 啵啵**：一句话带过概念，可以加一句“想细看，啵啵讲过”。
8. **啵啵 → 熊**：结尾停在判断前面，比如“天生的还是阶段的？这得问熊”。
9. **配对不是义务。** 只有一个话题两边都有料时才配对；单独成立的内容各自发。这与 7-11“不要求每条承担完整商业链路”一致。
10. **开挂的熊不等啵啵。** 啵啵那条还没做出来时，熊照常发，用一句话版本。主线不能被啵啵卡住。

## 五、示例：高敏感

熊这条的观点已定（10-31）：**很多人的高敏感，是所处的阶段带来的。** 先天的一面（包括“是礼物”）一两句带过；“痛苦是好事”单独做一条；例子从工作、选择、未来里找。

| 段落 | 三问结果 | 去向 |
|---|---|---|
| 开头：爆款都在讲“高敏感是礼物” | 熊的切入和立场 | 熊 |
| 高敏感是什么：心理学概念的由来、几个核心特征、大约多少人有 | 公共知识，一句讲不清 | **啵啵** · 熊稿只留一句：“心理学里，高敏感一般被看作一种天生的气质。” |
| 先天的一面：认可，是礼物 | 熊的态度，一两句 | 熊 |
| 为什么压力大、处在变动期时，人对外界的反应会变强 | 公共知识，一句讲不清 | **啵啵** · 熊稿只留一句 |
| 核心观点：很多人现在的高敏感，是阶段带来的 | 熊的判断 | 熊 |
| 怎么分清“是我这个人的问题，还是这个阶段的问题” | 对观众处境的判断 | 熊（对应 998 目录第一部分） |
| 工作、选择、未来里的例子 | 对观众处境的判断 | 熊 |
| 熊的原创模型（如“前端放大器增益高，消化管道长，容易反刍”） | 熊的原创模型 | 熊（用不用由作者定） |
| 一般怎么减少过载：通用做法 | 公共知识，“一般怎么做” | **啵啵** |
| 痛苦是好事 | 熊的判断 | 熊，单独一条（已定） |

结果是两条内容：

- **啵啵 · 学一个词「高敏感」**：是什么 → 为什么压力大时更敏感 → 一般怎么减少过载 → 结尾交接：“天生的还是阶段的？这得问熊。”
- **开挂的熊 · 熊熊烧烤摊「很多人的高敏感，是阶段带来的」**：一句话带过概念 → 观点 → 怎么分清 → 例子 → 结尾自然说出“一条视频讲不完”（链路三问第 3 问）。

**附带的好处**：10-31 熊这条写不下去，原因是“想把先天、礼物、阶段、痛苦都讲全”。按这套规则，想讲全的那部分知识交给啵啵，熊的稿子只剩判断，会好写很多。

**注意**：啵啵讲的心理学知识，制作前要核对出处；只讲公共知识和一般做法，不做诊断。

## 八、两个号怎么接，熊和啵啵是什么关系（作者 11-06 补充）

### 作者原话

> 补充一下，就是开挂的熊和波波这两个账号的配合方式。比如开挂的熊这个账号提出一个概念的时候，他说我我我不在这里深入展开了。这个时候啵啵就可以跳出来，说对，如果大家对这个知识点感兴趣的话，可以移步到我的主页。然后补充一下熊和波波。待定熊认为自己是波波的妈妈。这个比较打动触动女性的心理。相当于和用户更统一战线。但是只作为待定。这个的逻辑就是因为，啵啵是熊创造出来的。就像自己生出来一样，十月怀胎。但这种说法。也容易引人人的反感，所以说作为待定说法。但是不变的是熊认为啵啵是自己的孩子。但可能有的时候比较凶，或者比较严厉，会压榨啵啵。所以说啵啵管熊叫老板。未来可能也不会做太多熊和啵啵的感情方面的内容。大致是这样的一个设定，算是一个小巧思。保留一定的矛盾的张力在。

### 作者已定

1. **啵啵客串**：开挂的熊提到一个概念、说“这里不深入展开”时，啵啵跳出来，请感兴趣的人去啵啵的主页。这是第 7 条“熊 → 啵啵”的升级版。
2. **熊把啵啵当自己的孩子**（不变）：啵啵是熊造出来的。
3. 熊有时候比较凶、比较严厉，会压榨啵啵，所以**啵啵管熊叫“老板”**。
4. **熊和啵啵的感情戏少做**；保留一点矛盾的张力，算一个小巧思。
5. 【搁置，11-06】**“熊是啵啵的妈妈”这个说法**：逻辑是啵啵是熊造出来的，像十月怀胎生出来的；能打动女性观众，和用户站在一边；但也容易引起反感。

### Claude 的建议

**1. 张力在一个称呼里**：熊把啵啵当孩子，啵啵偏叫熊“老板”。一个当亲情，一个当雇佣，一个词就有了反差。这也接上了啵啵的反骨：他想单干，就像孩子想自立门户。很多人也有同感：家里那位严厉的长辈，就是自己的第一个老板。

**2. “妈妈”先不明说，用一个小梗来露**：熊偶尔说漏嘴“我家啵啵”，啵啵马上纠正：“叫老板。”亲情露出一点就收，暖意有了，又不用正面宣布“我是他妈妈”，招人反感的风险小。一句话的事，也符合感情戏少做。观众反应好，再考虑往前走一步。

**3. 客串怎么做**：

- 开挂的熊发视频：放一段可复用的啵啵探头小片段（3～5 秒，Grok 视频模型做一次，以后反复用），配一句台词；文案里 @啵啵大王。
- 开挂的熊发图文：放一张啵啵探头的图，文案里 @啵啵大王。
- 啵啵那条已经发了：指去主页。还没发：说“这个词我正在做，先关注我”。熊照常发，第 10 条“开挂的熊不等啵啵”不变。

**客串台词**（啵啵的口吻，备选）：

- “老板又不展开了……行吧，这个词我来。想听的，去我主页。”
- “老板讲重点，细节归我。想细看的，来我主页找我。”
- 还没做好时：“这个词我正在做，先关注我。”

**反过来，啵啵 → 熊**（第 8 条）：啵啵讲完词，停在判断前面：“这个词放到你身上怎么用？这得问我老板，去开挂的熊那儿看看。”

**4. 有现成的样子**：抖音上的“祝晓晗”和“老丈人说车”，一个是女儿视角，一个是爸爸视角，讲同一家人的故事；祝晓晗每条视频的文案都 @老丈人说车，老丈人还时不时出现在祝晓晗的评论区和网友互动（来源：tt123.com 的矩阵号案例文章）。熊和啵啵可以照这个路子：两个视角，同一家人，互相 @。

**5. 平台规则**：抖音 2023 年出了矩阵号新规，重点打击的是用多个小号发低质、同质化内容、刷粉刷赞，再把粉丝引到大号上牟取不当利益（来源：新华网、澎湃新闻的报道）。熊和啵啵两个号各自做原创、内容不重样，互相 @ 是在这之上加分。

- 其余理解没问题。
- **爸爸还是妈妈：搁置。** 熊是男生，不刻意设计的话，说熊是啵啵的爸爸也可以。但这涉及男女话题，比较敏感；熊的用户以女生为主，说“妈妈”可能招人好感，也容易弄巧成拙。保留这个思考，暂不应用。
