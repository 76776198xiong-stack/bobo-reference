# 用户菱形：定位收束

日期：2026-11-04（北京时间）｜整理：Claude（总控）｜状态：**第一至九节作者已认可**（11-04 讨论收束）；第十节状态带前四条是作者的版本，后两条是顾问草案；第十一节待讨论；第十二节“作者做的是什么”讨论中
经过和作者原话见重点待议：受众与故事（原记录引用：2026-11-03-重点待议-受众与故事.md；未随本包迁入）第七节。这一页只放结论。按场景整理的随身版：[用户卡](00-用户卡.md)。

**一句话**：心底希望自己过得更好、相信靠自己能做到、所以不满足于现在的人；他们都朝“开挂”这个方向走；当下的产品，服务其中刚起心动念、还不知道往哪走的那一段。

---

## 一、先分清三个词

- **用户**（商业）：用产品、买课的人。
- **受众**（内容）：写开挂的熊时，对着说话的人。
- **观众**（流量）：刷到视频的任何人。

要回答两个问题：**用户是谁**（底层，定商业模式和产品设计）；**开挂的熊在跟谁说话**（写作有具体的对话对象，选题知道怎么取舍）。两者是交集，不是谁包含谁。

## 二、怎么找：从产品反推

产品最主要的价值 → 它最能解决谁的问题 → 谁最有这个问题 → 谁最需要它。因为信任来买的熟人不算进来。

## 三、用户菱形

不是一条线，是一个方向：从一个起点张开成扇形，后半段两条边近似平行，最后在很远的地方收拢。**初心一致，殊途同归。**

- **起点**：刚起心动念。
- **边界（不变的特质，心底三条，按这个顺序）**：
  1. 希望自己过得更好；
  2. 相信自己能做到，而且是靠自己变厉害来做到（“靠自己”待作者确认）；
  3. 所以不满足于现在。

  这三条不随年龄增长、经历变多而变。
- **中间**：各人的路不同，比如上班、考研、做自媒体、创业。
- **节点**：一条条横穿所有路的状态带，按状态定，和走哪条路无关（草案见第十节）。
- **后半段**：两条边近似平行，越往后，共同的东西越多，主要是同一种思维方式。
- **归处：开挂。** 开挂是方向、状态、思维方式，不是终点；硬要说极限，是《道德经》里的“道”。
- **下线只有两种**：停下（无所谓、觉得够了），转向（不再靠自己）。不去想他们；但内容别把人推下线，也别把暂时低落的人算出去。

## 四、每句话都没毛病：两条检验

1. 能从产品最主要的价值推出来。推不出来的，降为“相关”。
2. 失去这一条，他就不在菱形里了。还在，就只是“相关”。

另外两条：核心只写状态，不写成因。年龄、性别、职业只有倾向性，没有因果性，只用来挑例子（同类账号的粉丝以年轻女性为主）；状态和信念才决定选不选题、对谁说。

春蚕过不了这两条检验：“被别人约束、为别人做嫁衣”不是每个人都有，“刚进入社会”会随年龄变。所以春蚕只作反讽。

## 五、现在的用户（998、破茧）

心底三条都有；眼下不知道往哪走，也不确定自己行不行；刚起心动念，还没开始。焦虑、怀疑自己的人是主体，他们比已经有把握、开始做的人多。已经开始做的人也是用户，买的是以后的产品。

## 六、菱形对商业的意义

- **两头尖，在那里的人都一样，适合做标品。** 998 在起点附近。
- **中间宽，产品有两种做法**：按状态做，横穿所有路，像 998；按路做，只服务一条路上的人，比如以后教做自媒体、赚钱。按路做的产品，要看作者自己在哪条路上拿到了结果：先自己拿到确定性，再卖。
- **开挂贯穿整个菱形**：前面是方法（998 用开挂理论分析具体问题），后面是方向。对外承诺的是方向，不是一个结果；破茧 198、终身，和“没有终点”对得上。
- 越靠后的产品，客单价越高；现在的啵啵、开挂的熊、明镜，都是给后面铺垫。

## 七、三个账号怎么用

| 账号 | 在菱形里 | 规则 |
|---|---|---|
| 啵啵 | 最宽的入口，观众可以是任何人（因为选题是泛知识），又和开挂的熊大致相同（因为形象和性格围绕核心用户的兴趣） | 选题门槛：对主要用户有帮助，很火但没帮助的不做（决策总表 E17）；下限：开挂的熊的受众看得懂；例子按倾向挑 |
| 开挂的熊 | 整个菱形，主攻起点那条带 | 门槛：对得上心底三条；主体：起点带的选题（高敏感就是）；偶尔可以对着靠后的人 |
| 杨傲雄 | 以后；菱形中间的一条路（自媒体、赚钱） | 作者在这条路上先拿到结果，再开 |

## 八、写作时的具体的人

核心固定（第三节的心底三条），每条内容现场生成一个人：先问“这个人会在哪个具体时刻撞上这个问题”，再按倾向给他配上年龄、工作和一天的生活。转折大多不是一件大事，而是“又一次”：又一次加班、又一次看到同龄人、又一次下了决心又回到原样。

## 九、什么时候用

| 什么时候 | 用哪几节 | 怎么用 |
|---|---|---|
| 开挂的熊挑选题（每条） | 三、四、七 | 链路三问（10-31）第 1 问“吸引来的是不是区间里的人”，改成“对不对得上心底三条”；主攻起点带 |

**顾问判断（待讨论）**

1. **什么才算 IP。** IP 的本义是知识产权。内容行业说的 IP，指一个能跨形式、跨产品被认出来、被买单的核心：角色、世界观、价值观。检验：离开某个账号、某种形式，还认不认得出来，还有没有人买单？露脸只是出镜方式。啵啵从账号走到明镜（决策总表 A9），就是 IP 在跨形式；所以作者的做法更接近 IP 的本义。“多账号的创业者”不冲突：IP 是核心资产，创业是在它上面做的生意。
2. **四种定位，圈人用的东西不同。** 人口（年龄、城市、收入）只有倾向；意识形态，看他怎么解释世界；心智（营销里一般来自特劳特的定位理论），看你在他脑子里占什么位置；这套，看他往哪走、卡在哪。前三种是静态的，这套是动态的，而且从产品反推，直接接到商业上。
3. **垂直有三种。** 话题垂直：做酒只讲酒。角色垂直：观众跟着角色看，啵啵是这种。方向垂直：话题不同，但都朝同一群人的同一个方向，开挂的熊是这种。作者举的喝酒的例子：那群人喝酒是想放松，讲放松的东西都算垂直。以后的杨傲雄更接近话题垂直（一条路）。
4. **“信仰定位”可以有内容。** 心底三条里的“相信自己能”，加上归处“开挂”，就是他相信什么、朝什么走。意识形态管他怎么解释世界，信仰管他往哪走、凭什么相信自己走得到。风险：“信仰”在中文里有宗教联想，平台审核和听感都要考究。
5. **要实用，就落成几个人人能答的问题。** 定位法草案（暂名“菱形定位法”）：① 从产品反推，还没有产品的，从自己已经跨过的那一段反推；② 写出心底不变的特质，用两条检验筛；③ 画出状态带：一路会卡在哪；④ 定方向：不是终点；⑤ 分层：账号和产品各管哪一段，选题按方向垂直，例子按倾向挑。
6. **称号的论据就在作者那句话里**：AI 能替代知识，替代不了一个人的方向和判断。卖知识的 IP 会被 AI 挤压，卖方向和判断的 IP 不会。称号候选：方向型 IP（最准）；北极星型 IP（北极星是用来认方向的，不是要走到的地方，和“开挂不是终点”对得上；“北极星指标”在商业圈也常用）；信仰型 IP（作者的词，最有力，风险见第 4 条）。没查到“心智型 IP”的出处。

**顾问判断 v2（按学员来想，待作者确认）**

- **学员的处境**：多半还没有产品，粉丝不多；常被告诉“要垂直”“要做画像”；常卡在不知道讲什么、被说不垂直、画像写了用不上、不知道卖什么。
- **核心说法：定位，是在一个方向上找到你站的位置，和你身后的人。** 不是在用户脑子里占一个位置（心智定位，适合已经有产品的品牌），也不是给一群人贴标签（年龄城市收入、意识形态）。
- **学员要答的问题，每一问都对应一个决定：**
  1. 你朝哪个方向走？决定账号长期讲什么：话题可以换，方向不换，这就是“看似不垂直，其实垂直”。
  2. 你已经跨过了哪几道坎？拿状态带对照自己的经历。决定你凭什么讲、能卖什么：只卖你跨过的坎；不用当专家，领先他一个身位就够。
  3. 谁在你身后？他心底有什么不变的东西（两条检验），眼下卡在哪道坎？决定你跟谁说话，第一个产品解决哪道坎。
  4. 他的倾向（年龄、性别、处境）是什么？只决定例子怎么举。
  5. 有了产品以后，从产品反推一次，校准第 3 问。
  6. 要开第二个号、做角色 IP 时：方向在最上面，IP 是方向下面的几张脸，账号和产品再往下。
- **为什么比现有方法有用**：答案都来自学员自己走过的路，不用编（春蚕的问题）；每一步都落到内容或产品的一个决定上；能解释话题不垂直、却很受欢迎的号；从一个号能长到多个 IP；在 AI 时代也站得住：知识越来越便宜，走在前面一个身位的那个人替代不了。
- **名字从核心说法里来**，等作者认了核心再定。候选：身位定位（领先一个身位）、坐标定位（方向加位置）。

**顾问判断 v3（待作者确认）**

- **信仰要这样定义才站得住：你相信、并且用行动验证过的方向。** 和意识形态的区别就在“验证”：意识形态是怎么看世界，不用付出什么；信仰要为它付出过。这样“信仰”也不会被理解成宗教。
- **创作者和用户信的是同一个东西，只是走到的地方不同。** 创作者是走在前面、验证过的人；用户是刚开始相信、还没验证的人。用户定义里的心底三条，就是“他信什么”；状态带，就是“验证走到了哪一步”。
- **对学员最实用的一问：你最近跨过的那道坎，是怎么跨过去的？** 答出来，就是他的第一个产品，也是他最有底气讲的内容。
- **商业个体和 IP 创业，各说对了一半。** “商业个体”说的是组织形式：一个人；“IP 创业”说的是核心资产：IP。两个都没装进最上面那一层：信仰。结构是：信仰在最上面，下面是一起相信的人，再下面是几个 IP（作者本人、啵啵），最下面是一道坎一个的产品。
- **称号候选：信仰型个体、信仰创业**，和“信仰定位法”成一套，正好和“心智定位、心智型 IP”对应。论据：AI 时代知识不稀缺，AI 也替不了人去相信、去验证。

**之前的初步看法（11-04 第一轮）**

1. **这套定位方法，是不是只适用于作者这类 IP？** Claude 初步看法：方法本身（三个词、从产品反推、因果与倾向、两条检验、账号分层）对任何有产品的个人 IP 都适用；菱形这个形状，适用于交付“人的变化”、用户会沿着阶段往前走的 IP（成长、职业、健身、学习等）。不同 IP 的差别，在张角的宽窄和有没有归处。纯娱乐、带货、一次性服务的 IP，用户不会沿着一条线往前走，只用得上前一半。张角越宽越难定位，不能按话题、行业、年龄来圈人，只能按状态和特质，这就是作者以前用年龄、性别、职业画像总觉得不准的原因。
2. **作者这类 IP 叫什么？** Claude 初步看法：判断标准是可替代性。传统个人 IP 卖的是一门技能或一个领域的知识，换一个同样懂的人也能卖；作者卖的是这个人本身的判断、思维方式和同行关系，换个人就不成立（破茧介绍原话：具体的人、具体的问题和长期形成的信任，无法被批量复制）。三个账号正好是三种：啵啵是角色型（跟着角色看），开挂的熊是方向型（跟着一个人的方向和判断走），杨傲雄以后是路径型（跟着一条路上的结果学）。名字候选：方向型 IP；同路人型 IP（取自“陪同路的人开挂”）；本人即产品。没有查过市面上有没有现成的叫法。
3. 啵啵：很火的题如果能落到用户身上，算不算有帮助；和 11-01 的“古代士兵什么时候逃跑”以哪个为准（决策总表 E17）。
4. “靠自己”这个说法准不准；状态带草案对不对。

**顾问判断（待作者确认）**

1. **“个人”修饰的是影响力和信用，不是组织规模。** 所以称号里不用“个体”。
2. **一条链把作者的话串起来：信仰 → 验证 → 信用 → 影响力。** 你相信一个方向（信仰），亲自做到（验证），别人因此相信你（信用），信你的人越来越多（影响力）。影响力最后有两个出口：产品，和一起做事的人。

   | 产品来自自己跨过的坎 | 教自己没做到的事 | 本文件十一 |
   | 关系往深处走：一起相信的人 → 用户 → 一起做事的人 | 一次性成交 | 作者 11-04 |

   人数不算限制：一个人、开公司都行。
4. **定义句草案**：以个人信用为核心资产，用口播公开展示自己相信并验证过的东西，聚起一起相信的人；把自己跨过的坎做成产品，再从这群人里找一起做事的人。
5. **和意识形态定位**：同意“真这么看，就会这么做”。差别在用法：一个人怎么看世界，外人看不见；他做过什么、跨过哪道坎，看得见。信仰定位法拿跨过的坎当证据，所以学员能检查自己，也能检查别人。没查到那位博主的意识形态定位具体怎么做，只能比到这一步。
6. **初心给菱形加了第二个出口**：一起相信的人，要么自己走（买产品），要么跟着作者一起干。所以公开的内容同时也是在找人：互相了解，靠的就是长期看得见的判断和做法。
