# 啵啵社交内容与连续小漫画 SOP v0.1

2026-11-12。状态：本地可执行草稿；已完成现有办公图“选图—配文—发布准备”的离线演练，未生成、未发布、未通过作者成品验收；小漫画尚未实跑。

用途：日常场景、朋友圈与平台图文、自恋萌照/生活反差、连续小漫画。知识解释继续使用原bobo-visuals，视频继续按其独立规则。此SOP不改上述正本。

## 1. 开始前只取必要输入

确认本次用途、观众要感受到的情绪/一个视觉事件、已有图还是需要生成、画幅和交付位置。作者已明确指定现有图时直接进入选图核对。世界可包括日常生活、出游、自拍、摸鱼、干活，不固定办公室、皇冠、王座，也不要求每条讲知识或证明商业价值。

人格与身份以`顾问意见/00-啵啵灵魂.md`、`00-啵啵决策总表.md`作者决定为准。原图引用`B-MASTER-001`并记录路径/哈希；上镜高光按B13，团子手按更新的B5a腮帮子出手，画面不需要手就不展示。场景图只提供创意参考，不自动改写角色母版。旧形体可留档，不作为新版形象输入。

## 2. 选择一条路径

| 路径 | 最小产出 | 停止点 |
|---|---|---|
| 日常场景/朋友圈单图 | 选一张已有图，核对画面和原件，配一段短文字 | 作者看图文后决定是否发布 |
| 自拍、萌照、自恋照 | 一个角色心理与表演动作；反差来自角色与处境 | 先看有趣、好看、可爱，再检查身份 |
| 社交平台图文 | 用途、已选图、短配文、平台需要的画幅/图序 | 平台要求未当次核验时先标待核，不虚构通用限制 |
| 连续小漫画 | 先做完整分镜：设置、行动、反转/收尾；建议2～4格起步，格数按内容 | 先确认故事，再按需要进入原生绘图对话 |

## 3. 最小执行顺序

1. **建内容卡**：复制`templates/社交内容卡-v0.1.json`为独立内容ID。只填事实，未知字段留空/待核。
2. **选图及看图**：打开文件，记录原始路径、类型、尺寸和SHA-256。区分原生生成图、截图、裁切与预览。已有选图不重复发散。创意认可、形象认可、可直接发布分别记。
3. **形成作品或配文**：现有图优先直接使用。确需新图才记录完整提示词、参考图用途和工具能力。生成环境必须真正看到母版，读取README/字节不算看过；缺工具或缺实际视觉输入时停在输入准备。生成授权以当前作者任务为准，不继承不相关任务。
4. **小漫画连续性**：逐格记录固定角色输入、场景锚点、镜头、道具位置、情绪和动作起止。每格用同一母版与已确认风格；上一格仅供连续性参考。角色原画由原生图像工具完成，排版可以组装现成格图。相邻格和整页都要看，避免角色/服装/道具突然换版。
5. **审核**：作品本身的笑点、情绪与审美；角色身份、表情和团子手；文字与发布画幅。身份/动作不明时写待作者核定，不把自动检查当创意验收。
6. **有限修订**：核心笑点已成立则只修实际问题。核心事件变了，另存新的创意版本。作者选择即收束，不因评分或缺失历史图再次启动探索。
7. **发布准备**：保留原图，另建发布目录，保存图文、平台、拟用图序与未决项；尺寸转换仅在有实际要求和授权时制作派生副本。作者批准前状态保持“待作者审阅”，不调用发消息/发布工具。
8. **发布后回填**：只有真实发布后填写时间、URL、平台ID和数据；当前留空。新反馈追加到审核记录，原版和提示词不覆盖。

## 4. 版本与最小目录

```text
BOBO-SOC-YYYYMMDD-NN/
  content.json                 内容卡与审核状态
  sources/                     参考/原始下载副本和来源索引
  prompts/prompt-v01.txt        完整实际提示词；没有就记缺失
  outputs/v01/                 本轮全部原始结果
  review/review-v01.md          作者原话与AI检查分开
  publish-prep/v01/             配文、拟发布图、平台及待核项
```

目录按实际发生建立，空的提示词或发布结果不伪造。每次输出记input文件哈希、prompt版本、会话/回合、output哈希、是否选中和出处。复制原件核验字节；原图一图多次上传可共用哈希，但消息关系全部保留。
