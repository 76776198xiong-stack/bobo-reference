# 啵啵（Obo）新需求汇总 · 2026-11-02

> 交给 Codex 做标准形象。来源：熊在 2026-11-01～02 与 啵啵·总管 的对话。原话加引号，其余为整理。
> 旧的 9 触手方案暂停；“33-Obo 9腿结构示意”图仍然禁止使用。

## 1. 结论
- 头部全保留：脑袋、表情、眼睛形状、嘴、耳朵，都按官方参考，不改。
- 身体重做：不要标准圆球，也不要固定触手。改成软软的、珍珠色的、不规则近球形。
- 手和道具：不要固定的一圈手，需要时可以在任意位置随时长出来。
- 性格：平常呆萌，跟人交谈时积极阳光，底色暗藏腹黑。

## 2. 形体
- 默认状态是“软软的不规则的近球形”。
- 不规则的原因是它够软，撑不住完美的圆，所以轮廓有轻微、随意的变形。
- 不要的形体：
  - 标准正圆；
  - 下端左右各一个凸起；
  - 摊成一摊的样子（熊原话：“不想要这样一摊的感觉”）；
  - 果冻坐姿团。
- 质感要“很好吃、很好玩”，让人想捏一捏、咬一咬。
- 手和道具随用随长，长在哪都行。参考 Grok Bot 教学视频里那个能变形的小黑点。

## 3. 颜色和材质
- 熊原话：“还是橙色比较好看。”
- 在橙色基础上做出珍珠的感觉。
- 熊澄清，珍珠感指的是珍珠的颜色本身（乳白、暖色珠光），不是靠加高光、堆特效做出来的。
- 色彩参考：`refs/pearl-color-ref-xhs.jpg` 左边两张。
  - 左上：白底白珍珠，带微微的粉紫珠光。
  - 左下：黑底，彩虹珠光，暖橙、粉、蓝渐变。
- 粉色、薄荷、奶白不当主色。

## 4. 性格（指导表情和动作）
| 状态 | 表现 |
|---|---|
| 平常、待机 | 呆萌：反应慢半拍、眼神放空一下、动作软乎乎 |
| 跟人交谈、讲解 | 积极阳光：眼睛亮、说话干脆、愿意帮忙 |
| 底色 | 腹黑：用一本正经的短句、反问或装傻噎人一下，马上收回阳光，不恶毒 |

- 原来以“拽拽的”为主的性格，现在弱化。
- 动作和表情要自然灵动，偶尔奇葩、抽象、可爱、搞笑。
- 表情可以参考 Claude v0.1 那套：眼睛先动、身体跟上，眨眼和情绪切换的节奏。

3. 不要给熊看零件或装配检查图，只给成品图或动起来的片段。
